市场背景

为什么 2026 是 Agent 元年

技术、成本、生态三重要素在 2026 年同时跨过临界点：基础模型推理成本下降一个数量级、长上下文与工具调用能力成熟、企业级 SaaS 集成标准成形。

技术临界点

多模态 + 工具调用成熟

Claude Opus 4.5/4.8、GPT-6、Gemini 3.5 在 OSWorld、WebArena 等 Agent 基准上首次突破 60% 任务完成率，跨越了「可用」到「能交付」的分水岭。

成本临界点

推理价格腰斩

Gemini 3.5 Flash 在 Google I/O 2026 宣布「免费 + 4 倍速」，将 Agent 推理单价压至历史低点；OpenAI、阿里同步下调 API 价格，Agent 单次任务成本进入「分」级别。

生态临界点

平台型 Agent 出现

扣子 Coze 3.0、阿里千问 App 已演化为「Agent 操作系统」：支持多 Agent 协作、行业技能包、一键发布到飞书/抖音/微信等终端，生态护城河初步建立。

商业化临界点

从订阅到按效果计费

Codex 年化收入突破 25 亿美元、Sora、Agent 任务调用量爆发，企业市场开始接受「按结果付费」模式。Gartner 预测 2027 年 40% 企业员工将由 Agent 辅助。

产品深度拆解

五大主流 Agent 全景对比

从定位、能力栈、定价、商业化指标、市场反应五个维度，建立可对照的产品坐标系。

OpenAI Operator / ChatGPT Agent
OpenAI · 美国
  • 定位：通用网页/桌面任务执行 Agent，基于自研 CUA（Computer-Using Agent）模型，2025-01-23 首发，2025-07-18 整合为「ChatGPT Agent」统一品牌。
  • 能力栈：融合 Operator 网页交互、Deep Research 信息搜集、ChatGPT 对话三套核心能力；2026-04-14 发布 GPT-6（代号 Spud）后，进一步强化记忆与个性化，被官方定义为「AGI 最后一公里」。
  • 定价：Operator 早期仅限 ChatGPT Pro（$200/月）；2026 年同步推出 ChatGPT Pro Lite（$100/月）和 Max 20x（$200/月），按调用阶梯定价。
  • 商业化指标：Codex（编程 Agent）年化收入 25 亿美元，自 2026 年初增长超 100%，是 OpenAI 内部增速最快业务线。
  • 市场反应：金融分析师使用 ChatGPT Agent 自动生成 PPT 与 Excel，OpenAI 临时直播活动引爆关注；开发者社区称其「真正具备自主性」。
Anthropic Computer Use / Claude Code
Anthropic · 美国
  • 定位：面向企业的桌面级 Computer Use Agent，2024-10 首次以研究预览版发布，2026-03-23 正式版上线，集成进 Claude Cowork 和 Claude Code CLI。
  • 能力栈：macOS 桌面原生控制（打开 App、点击、输入、截图、文件处理）；通过内置 MCP 服务器集成，无需 Docker/虚拟机；要求 Claude Code v2.1.85+、macOS、Pro/Max 订阅。
  • 模型底座：Claude Opus 4.5（2025-11）、Claude Opus 4.8（2026-05-29），在长上下文、代码、推理上保持领先。
  • 商业化指标：Claude Code 已成为 Anthropic 收入支柱，企业版（Claude Enterprise）提供 SSO、审计、长上下文管控，2026 年 ARR 增速最快业务线之一。
  • 市场反应：被业内视为「真正接管电脑」的标志产品；安全研究者提示需配合人在回路（HITL）机制；与 OpenAI Operator 形成「OS 级 vs 浏览器级」路线分野。
Google Gemini Agent Family
Google DeepMind · 美国
  • 产品矩阵：Project Mariner（Chrome 浏览器 Agent，2024-12）、Project Astra（多模态通用 Agent）、Jules（异步编程 Agent，2025-08 正式发布，基于 Gemini 2.5 Pro）、CodeMender（安全漏洞修复 Agent）。
  • 核心节点：2025-11-18 发布 Gemini 3 Pro，被誉为「综合实力最强」模型；2026-05-19 至 21 日 Google I/O 大会连发 13 项更新，主题为「AI 的 Agent 时代」。
  • 旗舰更新：Gemini 3.5 Flash（免费 + 4 倍速，碾压 GPT-5.5）、Project Antigravity 2.0（IDE 级 Agent 开发环境）、Spark、Omni 全家桶。
  • 定价策略：延续 Google 经典的「免费 + 高级订阅」路线，3.5 Flash 把推理成本打到零门槛，倒逼全行业价格下移。
  • 市场反应：Jules 被开发者称为「真异步编程助手」，与 GitHub Copilot 形成差异化；Gemini 智能眼镜将于 2026 上市，标志 Agent 向硬件延伸。
阿里通义千问 Agent / 千问 App
阿里巴巴 · 中国
  • 定位：中国最大 C 端 AI Agent 应用之一，2025-03 与通用智能体平台 Manus 战略合作，推动 Agent 从概念走向规模化。
  • 能力栈：通义千问 Qwen3 / Qwen3.5 系列模型为底座；千问 App 内置任务规划、代码执行、长文档处理、深度研究等多模态 Agent 能力；2026 年支持一键调用 Manus 工作流。
  • 商业化指标：QuestMobile 2026 数据：千问月活 1.65 亿，同比暴涨 4241%，增量 1.26 亿，AI 原生 App 月活 TOP10 排名第二，增速第一。
  • 商业化路径：API 日调用量已破亿，企业用户超 9 万，开源模型下载量 700 万次；通过阿里云、淘宝、钉钉、闲鱼等场景分发 Agent 能力。
  • 市场反应：被业内称为「2026 年用户增长最快应用」；凭借本土化、合规、中文理解优势，挤占 ChatGPT、文心一言市场份额。
字节扣子 Coze 3.0
字节跳动 · 中国
  • 定位：一站式零代码 Agent 开发与分发平台，海外版 coze.com、国内版 coze.cn 双线运营。
  • 3.0 重磅升级（2026-06-03）：支持多人多 Agent 协作；金融、自媒体、医疗、法律、科研等行业技能包；一键加载、多端同步；可直接接入 Claude Code、Codex CLI、OpenClaw 等外部 Agent。
  • 分发渠道：与抖音深度打通，提供「创作者 AI 分身」能力；一键发布到豆包、飞书、微信公众号，构建国内最广分发网络。
  • 商业化指标：插件库超 60 种、覆盖新闻、旅行、生产力、图像理解等场景；2026 年被浙商证券判断为「AI Agent 商业化新拐点」。
  • 市场反应：零代码 + 强分发的「抖音式」打法，让 Coze 在 C 端创作者、中小企业中快速渗透；与阿里千问 App 形成「平台型 vs 应用型」对照。

商业化进展

从订阅到效果付费，分化加速

海外巨头押注「高客单价 + 企业级」；中国玩家押注「低门槛 + 高用户量」。两条路径都已被验证可行。

海外路线

高价值任务 × 企业订阅

OpenAI Codex 年化收入 $25 亿、Anthropic Claude Code 在金融/法律行业渗透、Gemini Enterprise 捆绑 Workspace 销售。共同特征：按席位 $100–$200/月 + API 用量分成，目标客户为大型企业知识工作者。

中国路线

低门槛 × 高用户量

阿里千问月活 1.65 亿、增量 1.26 亿；扣子 Coze 创作者 AI 分身与抖音深度绑定。共同特征：免费 + 增值服务 + 流量分发，把 Agent 嵌入既有国民 App（淘宝、钉钉、抖音），构建不可替代的场景护城河。

垂直渗透

金融 / 医疗 / 制造

核心洞察

研析判断：六大趋势

基于五大产品对比与市场反馈，我们提炼出 2026 上半年 AI Agent 行业的六条核心趋势。

01 · 路线分野

OS 级 vs 浏览器级

Anthropic 押注 OS 级（Computer Use + macOS 桌面），OpenAI 押注浏览器级（Operator + ChatGPT Agent）。两条路线的胜负将决定下一阶段的 Agent 范式。

02 · 平台战争

从模型到 Agent 平台

扣子 Coze 3.0、千问 App、Gemini App 都已演化为 Agent 平台。模型可插拔、Agent 可分发、生态可累积——平台层是新护城河。

03 · 定价分化

高客单价 vs 高用户量

海外巨头走 $100–$200/月企业订阅 + API；中国玩家走免费 + 增值 + 流量分发。两种模式各有护城河，短期难分胜负。

04 · 硬件延伸

Agent 走出屏幕

Google Gemini 智能眼镜 2026 上市、Siri + Apple Intelligence 蓄势待发。Agent 正从软件向硬件全场景延伸。

05 · 安全与合规

人在回路成标配

Computer Use 上线后，安全研究者提示需 HITL（人在回路）；Claude Enterprise、扣子 Coze 行业技能包都开始把审计与权限控制做成标配。

06 · 垂直落地

金融 / 医疗 / 制造先行

三大行业占企业级 Agent 订单 100%；金融单均合同 ¥386 万，验证「高价值垂直行业」是 Agent 商业化最稳路径。
