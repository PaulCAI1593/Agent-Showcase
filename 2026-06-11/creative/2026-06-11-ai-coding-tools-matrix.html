05 · 演进时间线

从 Copilot 到 Agent

AI 编程工具的演化路径 — 从单行补全到自主 Agent,每一次范式跃迁都重塑了开发者工作流。

2021 · COPILOT 时代
行内补全范式
GitHub Copilot 发布,基于 Codex 模型实现单行 / 函数级补全。"AI 副驾驶"概念被验证。
2023 · CHAT 时代
对话式编程
ChatGPT + Copilot Chat 兴起,开发者开始通过自然语言与代码对话。Cursor 凭"AI-first IDE"差异化突围。
2024 · EDITOR 时代
多文件编辑
Cursor Composer、Claude Code 发布。AI 不再补全单行,而是理解整个代码库,跨文件改写 + 提交。
2025 · AGENT 时代
自主 Agent
Sub-agent、工具调用、CI 集成。AI 编程工具从"辅助"演化为"协作成员",开始独立完成 PR 与部署。
2026 · ORG 时代
组织级 AI 工程师
企业将 AI 编程 Agent 纳入研发流程,KPI 绑定、人机协作协议、AI 代码审计成为新基建。三款产品成为基础设施。
