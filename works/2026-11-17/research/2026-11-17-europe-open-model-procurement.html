56 块 B200 与十分之一的账单

欧洲最大的科技创业公司之一，把两千名工程师的默认编程模型从 Claude Code 与 Codex 换成了自托管的智谱 GLM。这不是一次模型选型新闻，而是一次采购结构变更：模型从「按 token 计费」变成「按小时计费的固定资产」。

核心判断

这次换模型赢的不是榜单，是账单结构。

闭源 API 的定价随 token 走：工程师写得越多，账单越大，于是账单本身成了生产力的天花板。Revolut 的做法是把这台机器买下来：56 块 B200 是自有固定资产，闲置一整天和工作一整天价钱相同，于是「多写一点」不再等于「多付一点」。开源权重模型能不能赢、能力是不是更强，都不是这件事的关键；关键是模型运行时归谁所有。

但这条结论有边界：90% 降的是 token 账单，不是总成本。GPU 采购、机房、电力、推理平台的运维人力没有被计入分子。报道本身也点明了这一点：把 56 张卡和它们的固定成本摊进每天的调用量之后，单 token 成本才降到 0.30 美元。

88% 与 76% 是一对，必须一起读。需求涨了 76%，单位成本同时降了约 90%：这不是「模型变聪明了」，是「同样的卡扛住了更多请求」。两张数据放在一起才说明自托管摊薄的机制：利用率越高，每 token 越便宜。

十四个月的时间线

这不是一次模型发布当天的决定。Revolut 先用了一年多的闭源 API，才在账单压不住的时候改道。

  • 2025-01
    先用起来：Gemini 与 Claude Code
    Revolut 2025 年 1 月开始试用 AI 编码工具，先引入谷歌 Gemini 用于内部数据访问，随后测试 Anthropic 的 Claude Code。AI Scout Daily 2026-11-09；The Register 2026-11-03 转述
  • 2026 年初
    账单压不住，改用预算上限硬控
    部分工程师每月在 AI 编码工具上花掉 1,000 美元至上万美元，投资回报却不明显。Revolut 给 Claude Code 设了严格预算上限，工程师只能领到有限词元。TechGig 2026-11-04；科技日报 2026-11-05
  • 2026-04
    智谱发布 GLM-5.1，Revolut 立刻自托管
    智谱于 2026 年 4 月推出 GLM-5.1，Revolut 迅速研究本地化部署并把它设为默认编码模型：实测使用成本仅为 Claude Code 的十分之一。词元配额随之取消。科技日报 2026-11-05
  • 2026-10
    AI Engineer 会议（纽约）：David Abitbol 演讲
    Revolut 负责 AI 运营与基础设施的 Abitbol 公开讲述自托管的模型、硬件与账单结构。具体演讲日各家报道不一致：AI Pulse 记为 2026-10-13，Art of Smart 与 nosov 记为 2026-10-29 录像上传日，此处存疑不裁定。
  • 2026-11-01
    Databricks 跟进：GLM-5.2 也被设为默认
    英国《泰晤士报》报道，美国 AI 与数据公司 Databricks 已将智谱 GLM-5.2 设为默认编程工具。开源权重的默认地位从欧洲扩散到美国。科技日报 2026-11-05 转引

口径与未确认

这套数字是演讲与媒体转述，不是审计过的财务数据。下面逐条标出它能证明什么、不能证明什么。

  • 90% 是 token 账单口径，不是总成本口径。分子是付给 Anthropic 与 OpenAI 的推理账单；GPU 采购摊销、机房、电力、推理平台运维人力不在其中。把 56 张卡的固定成本摊进去之后，才是「每百万 token 0.30 美元」这个混合单价。
  • 60% 与 70% 是自报交付指标，无对照组。没有同规模团队用闭源模型跑同一段时间的对照，也没有质量回退的评测。多家报道均把它们描述为公司自身的指标。
  • 88% 与 76% 出自同一场演讲，不构成独立交叉验证。两者的统计口径（测量窗口、基线、是否含冷启动）在报道中没有展开。
  • ≈ 3.00 美元/百万 token 是反推值。由「十分之一」这一表述与 0.30 推出，精度只到数量级，不可当作任何厂商的报价引用。
  • 「开源」这个词要打折。GLM 是开放权重模型，不是 OSI 认证的开源软件：许可证的具体条款在各家报道中均未展开。把它算作「开源阵营」是媒体与本文的简化，权利边界未确认。
  • 演讲具体日期各家报道不一致。2026-10-13 与 2026-10-29 两种说法并存，差别可能来自「演讲日」与「录像上传日」，本文不裁定。
  • 56 块 B200 的采购价未公开。确认方法：等 Revolut 或其披露义务主体（英国上市公司披露口径）给出资本开支数字，或等同配置 DGX B200 的市场成交价区间披露。
  • 数据驻留与合规安排未披露。确认方法：等 Revolut 发布面向监管的说明，或等欧盟 AI 法案相关部署登记信息可查。

一句话收束。Revolut 用 56 块卡把「模型在哪里运行」这件事从供应商的定价表里拿回到了自己的资产负债表上。这是开源权重模型第一次在成本结构层面压过闭源 API：不是因为它更聪明，而是因为它可以被买下来并一直开着。Databricks 隔天跟进，说明这不是个案，是采购侧的一次集体转向。
