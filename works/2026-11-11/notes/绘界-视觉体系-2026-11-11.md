## 0. 一句话结论

用**深灰蓝播控台底板 + 一青一橙红两个方向信号色**承载「降级 / 升级」二元叙事：颜色编码**方向**不编码国家，形状（圆点 / 三角）二次编码方向以规避色觉障碍；** rhetoric（平衡针）与 price（三只仪表）严格分离**，仪表用「实心指针 = 快照 + 空心三角标 = 盘中极值 + 区间底纹」表达两个时点，绝不混用。

## 1. 色彩方案

### 1.1 设计原则

| 原则 | 落地方式 |
|------|----------|
| 深色播控台 | 底板 `#0A0E13`，面板 `#131A22`，抬升 `#1B2430`——三层冷灰蓝，无渐变、无毛玻璃 |
| 方向色只有两个 | 降级青 `--deesc`、升级橙红 `--esc`；其余全部中性 |
| 颜色 = 方向，形状 = 方向 | 双重编码，色觉障碍用户只读形状即可 |
| 警示色不参与方向 | `--warn` 仅用于「盘中极值标记」与「押注揭晓」，与两方向色不共轴 |
| 数字用金 | `--gold` 只用于黄金仪表读数，避免三仪表读数被误读成方向信号 |

### 1.2 色板与对比度（WCAG 2.x 实测）

### 1.3 使用约束（硬性）

| 约束 | 理由 |
|------|------|
| **不得使用国旗色作为装饰** | 明确要求。青 / 橙红 / 白三色不得同时以色块形式出现，避免被读成国旗 |
| **不得使用任何军事或极端主义符号** | 不出现旗帜、鹰、星星、交叉刀剑、军装、徽章、武器剪影 |
| 方向表达只用几何形状 | 圆形节点 = 降级，三角节点 = 升级；箭头只用几何折线，不使用符号字体 |
| 不得用 emoji 当图标 | 所有图形为内联 SVG / CSS 几何 |
| 面板一律冷灰蓝，不用纯白大面积 | 维持播控台质感，压缩焦点在方向色上 |
| 方向色不用于正文长段落 | 仅用于状态标记、数值、图形；长文用 `--ink` / `--ink-2` |
| 失焦态不得靠 `opacity` 降低文字 | opacity 会把 15:1 压到 4.5:1 以下；改用替换 `--faint`（5.00:1） |

### 1.4 语义分工（避免误读）

| 图形 | 含义 | 不要承担 |
|------|------|------|
| **平衡针（中缝）** | 净**表态**方向（修辞层） | 不表示价格、不表示国家 |
| **三只仪表** | 市场**读数**（价格层） | 不表示某方立场 |
| **事件块颜色 + 形状** | 单条**表态**方向 | 不表示事件重要性 |

> 三层不可混轴。押注游戏的「揭晓」必须让读者一眼分清：他猜的是「表态」，实际答案是「价格」。

## 2. 图形语言

### 2.1 三只模拟仪表（SVG 画法）

#### 2.1.1 通用几何

| 项 | 规格 |
|----|------|
| 画布 | `viewBox="0 0 240 140"`，`preserveAspectRatio="xMidYMid meet"`，CSS `width:100%; height:auto; display:block` |
| 表盘弧 | 半圆，中心 `(120, 120)`，半径 `92`，扫角 180°（从左 180° 到右 360°），即水平左端 → 右端 |
| 弧线样式 | `stroke-width: 8`，`stroke-linecap: round`，底弧 `--line`；已读区段叠一层方向色弧 |
| 刻度 | 主刻度 5 个（每 36°），次刻度每主刻度间 4 个（每 9°），共 21 根；主刻度长 `10` / 粗 `2`，次刻度长 `5` / 粗 `1`，色 `--line` |
| 刻度数字 | 仅标 5 个主刻度，`11px`，`--faint`，`font-variant-numeric: tabular-nums` |
| 指针 | **宽根窄尖楔形多边形**，根部宽 `6`、尖端宽 `2`、长 `74`；尾端接一个 `14` 直径的圆形配重块（`--needle` 描边 `2`）——比发丝线指针在 100px 小尺寸下更易读 |
| 指针颜色 | `--needle`（中性），**不使用方向色**——方向色留给表态层，避免语义串线 |
| 指针 pivot | `transform-box: view-box; transform-origin: 120px 120px;` |
| 读数 | 盘腹内居中，`clamp(26px, 7.5vw, 46px)`，`600`，`tabular-nums`，`--ink` |
| 单位 / 名称 | 读数下方 `11.5px`，`--muted`，`letter-spacing:.08em` |

#### 2.1.2 两只时点如何**不混用**（核心机制）

三只仪表中只有布伦特同时存在两个时点：**快照 94 美元**与**盘中低点 90 美元**。用三件套区分，同一时刻只允许其中之一承载"当前值"：

| 元素 | 承载的时点 | 画法 | 语义 |
|------|-----------|------|------|
| **实心指针** | 快照 / 收盘读数 | 楔形多边形，`--needle` 实心 | 唯一代表"现在是多少"的部件 |
| **空心三角标** | 盘中极值 | 顶点朝上的**空心**等腰三角形（边长 `8`，`stroke-width:1.5`，`--warn`，无填充），贴在弧线**外侧** `r=104` 处 | 历史极值标记，不是当前值 |
| **区间底纹** | 两者之间的区间 | 圆弧 `stroke-width: 8`，`--warn-a07` 实心填充，仅覆盖 90°→该值之间的角度 | 一眼看出"这一段被打过" |

**规则**

1. 空心三角标**永远在弧外侧**，指针**永远在弧内侧**，两者在半径上不可能重叠 → 视觉上永不错读。
2. 空心三角标**不用方向色**（升级橙红 / 降级青），固定用 `--warn`。因为"跌到 90"不是"升级表态"。
3. 三角标旁标注文字 `盘中低点 90`，`11px`，`--muted`，与快照读数**分两行**排布。
4. 指针数字**只显示快照值**。任何时候不把三角标的值当读数显示。

#### 2.1.3 三只仪表的显示窗口与读数

> 显示窗口是**为可读性选定的坐标区间**，不是数据极值范围。窗口两端在轴上以 `--faint` 数字标注，避免读者误读为全区间。

| 仪表 | 显示窗口 | 轴主刻度 | 快照读数 | 第二时点 | 方向色用法 |
|------|---------|---------|---------|---------|-----------|
| 布伦特原油 | 80 – 100 USD | 80 / 85 / 90 / 95 / 100 | **94**（实心指针） | 盘中低点 **90**（空心三角 + `--warn` 区间底纹） | 指针下方加 `▼` 几何三角，`--deesc` |
| 现货黄金 | 4000 – 4200 USD/oz | 4000 / 4050 / 4100 / 4150 / 4200 | **4100** | 无 | 指针下方加 `▲` 几何三角，`--esc` |
| 10 年期美债 | 4.40% – 5.00% | 4.40 / 4.55 / 4.70 / 4.85 / 5.00 | **4.87%** | 无 | **不加方向色**（见下方说明） |

**关于 10 年期美债的克制处理**：收益率上行不是地缘升级的干净代理变量，给它涂上方向色等于替读者下结论。此处刻意用中性 `--needle`，只给 `▲/▼` 几何箭头与 `--muted` 文字，读者自行判断。若要参与"市场读哪一边"的加权，建议权重最低（见 2.4）。

#### 2.1.4 押注揭晓时的仪表动效

1. 指针从「窗口左端 -90°」弹到目标角 → 2.3 节
2. 读数数字 count-up（`requestAnimationFrame` + ease-out-cubic，640ms）
3. 空心三角标与区间底纹**延迟 300ms** 淡入（`opacity 0→1`，280ms），让"快照"先到、"盘中低点"后到，叙事顺序正确
4. 三只仪表依次揭晓，间隔 180ms（布伦特 → 黄金 → 美债），最后合并出净读数

### 2.2 事件脉冲块

#### 2.2.1 形状系统（颜色 = 方向，形状 = 方向）

| 方向 | 左侧标记 | 形状定义 | 颜色 |
|------|---------|---------|------|
| 降级 | **圆点** | `circle r=4` 实心 | `--deesc` |
| 升级 | **三角** | 顶点朝上的等腰三角，底宽 `9`、高 `8`，实心 | `--esc` |

块体本身：`border-radius: 6px`，`border: 1px solid` 方向色低透明版，左侧 `3px` 方向色竖条作为「口」的标识——一条轨上的每个块就是那一方的一张嘴。

#### 2.2.2 五种状态

| 状态 | 边框 | 底色 | 标记 | 文字色 | 变换 |
|------|------|------|------|------|
| **默认** | `1px` 方向色 @ 35% | `--deesc-a07` / `--esc-a07` | `opacity .55` | `--ink-2` | 无 |
| **悬停** | `1px` 方向色 @ 70% | `--deesc-a12` / `--esc-a12` | `opacity .85` | `--ink` | `translateY(-1px)`，140ms |
| **选中** | `1.5px` 方向色实 | `--deesc-a18` / `--esc-a18` | `opacity 1` | `--ink` | `translateY(-1px) scale(1.02)` + `box-shadow: 0 0 0 3px` 方向色 @ 18% |
| **降级态** | 同上三档 | — | 圆点 | — | `--deesc` |
| **升级态** | 同上三档 | — | 三角 | — | `--esc` |

**附加态：失焦（同轨其它块被选中时）**

- 边框降到 `1px` 方向色 @ 20%，底色回落到 `--deesc-a07`，标记 `opacity .45`
- 文字**换成 `--faint`**（对抬升面板 5.00:1），**不要用 `opacity: .35`**——那会把 `--ink-2` 的 9.79:1 压到 3.4:1，直接违反 4.5:1 硬指标

#### 2.2.3 结构与排版

```
┌─────────────────────────────────────────┐
│▌ ○  11-10 08:20  伊朗总统宣布结束「不战不和」│  ← 块首：标记 + 时间戳
│▌    军方向学说转向进攻，革命卫队称摧毁近10部雷达│  ← 块身：逐字引语
└─────────────────────────────────────────┘
```

- 时间戳 `11.5px`，`--faint`，`tabular-nums`，`letter-spacing:.04em`
- 引语正文 `14px`，`line-height:1.45`，`--ink-2`，**中文衬线**（见第 3 节）
- 引号用中文全角 `「」`，不使用 ASCII 直引号

### 2.3 平衡针（拉锯线）

#### 2.3.1 形态

| 部件 | 规格 |
|------|------|
| 主线 | 1px 竖直发丝线 `--line`，自中缝顶部延伸至 pivot，长度随断点调整 |
| 头部指针 | 指向净表态方向的小三角（横向），`10 × 9`，实心 `--deesc` 或 `--esc` |
| 枢轴 | `r=5` 空心圆环，`stroke-width:1.5`，`--line-strong` `#3D4C5C` |
| 中性区 | 中轴一条 `1px` 竖向虚线（`stroke-dasharray: 2 4`），`--line`，标 `0` |
| 轴标 | 中缝底部三个刻度 `−1 / 0 / +1`，`10.5px`，`--faint` |

#### 2.3.2 摆动规则

- 摆角范围 **±16°**，线性映射表态净方向到 `[-1, 1]`
- 净方向为 0 时，针**垂直静止**，指向中性虚线，不做"待定"抖动
- 针的颜色取**净方向**的颜色，而不是"最后点击的那条"——颜色代表方向这一层在整个视觉系统中保持一致
- 中缝同时显示两条「张力条」：每条轨下缘一条 `3px` 高的水平条，长度 = 该轨净方向绝对值，颜色 = 该轨净方向色；两条都指向中缝，形成"拉锯"的物理感

#### 2.3.3 中缝的整体构图

```
   ▏  伊朗轨（上）
   ▏  ▌○▌○▌▲▌              ← 事件脉冲块
   ▏  ━━━━━━━               ← 伊朗轨张力条
   ▏     ╱│                   ← 平衡针（摆动）
   ▏   ○  │  0               ← 枢轴 + 中性虚线
   ▏  ━━━━━━━               ← 美国轨张力条
   ▏  ▌▲▌○▌●▌              ← 事件脉冲块
   ▏  美国轨（下）
```

### 2.4 押注游戏的视觉规则

| 元素 | 画法 |
|------|------|
| 猜测滑块 | 横向轨道 + 一个可拖动手柄，手柄是 `20×20` 的圆角方块（`--ink-2` 描边），轨道内分成三段等宽：左 `降级` 青 / 中 `不确定` 中性 / 右 `升级` 橙红，三段之间用 `1px` 竖线分隔 |
| 未揭晓状态 | 三只仪表指针停在**窗口左端** `-90°`，读数显示 `—`，指针**不可见**（`opacity:0`），只留弧线——避免读者从指针位置偷看答案 |
| 揭晓瞬间 | 指针淡入 + 弹动；读数 count-up；三只仪表依次揭晓；净读数以一行**大字**居中于仪表行上方：`市场读：降级一侧` |
| 揭晓后的情绪 | 猜对时净读数用 `--deesc`，猜错**不用红色报错**——用 `--warn` 底纹 + 中性字，不制造对立感 |

**"市场读哪一边"的推导规则（需作者确认，见待确认项）**

建议权重：**黄金 0.5 / 布伦特 0.3 / 10Y 0.2**——黄金是避险定价的干净代理。计算式：

```
score = 0.5 × sign(黄金方向) + 0.3 × sign(布伦特方向) + 0.2 × sign(美债方向)
市场读 = score > 0 ? 升级一侧 : score < 0 ? 降级一侧 : 不确定
```

权重是**编辑判断**，不是数据结论，建议在文末以弱化文字标注「权重为编者设定」。

| 仪表读数（大数） | `clamp(26px, 7.5vw, 46px)` | 1.05 | 600 | `-0.01em` | sans | `--ink` |
| 仪表名称 / 单位 | `11.5px` | 1.4 | 500 | `0.08em` | sans | `--muted` |
| 时间戳 | `11.5px` | 1.4 | 400 | `0.04em` sans | `--faint` |

### 3.3 中文衬线引语 + 无衬线 UI 的搭配规则

1. **分工明确**：一切"人说过的话"用衬线，一切"系统说的话"用无衬线。时间戳、出处、刻度、数据标签永远无衬线——让读者一眼分辨**引语**与**标注**。
2. **字号差拉开层级**：引语 ≥ 19px，标注 ≤ 12.5px，中间不放 14–18px 的"中间字号"给引语，避免与 UI 打架。
3. **衬线加一点点正字距**：中文衬线在大字号下略显松散，引语用 `0.005em`–`0.01em` 正字距，标题用 `-0.02em` 负字距收紧。
4. **数字一律 tabular**：所有读数、刻度、时间戳加 `font-variant-numeric: tabular-nums`，避免指针弹动时数字左右跳动。
5. **引号用全角**：`「」` 或 `""`，不用 ASCII 直引号；引语整体不再额外加装饰引号图形。
6. **衬线不加粗到 700**：中文衬线 600 以上笔画糊，标题最高 600，引语保持 400。

## 4. 动效建议

### 4.1 数值总表

| 动效 | duration | easing | transform | 触发 |
|------|----------|--------|-----------|------|
| 入场（轨 / 块逐个） | `560ms` | `cubic-bezier(.22, 1, .36, 1)` | `translateY(12px) → 0` + `opacity 0 → 1` | 载入一次 |
| 入场 stagger | 每块 `+70ms` | — | — | 同上 |
| 事件块悬停 | `140ms` | `cubic-bezier(.2, 0, .2, 1)` | `translateY(-1px)` | hover |
| 事件块选中 | `180ms` | `cubic-bezier(.22, 1, .36, 1)` | `translateY(-1px) scale(1.02)` | 点击 |
| 脉冲呼吸（选中态） | `2600ms` | `ease-in-out` | `scale(1 → 1.05)` 无限 alternate | 选中后常驻 |
| 脉冲外环扩散 | `2600ms` | `ease-out` | `box-shadow: 0 0 0 0 rgba(c,.30) → 0 0 0 7px rgba(c,0)` | 同上 |
| 指针弹动 | `720ms` | `cubic-bezier(.34, 1.32, .64, 1)`（约 6% 过冲） | `rotate(-90deg → 目标角)` | 揭晓 |
| 指针微阻尼 | `110ms × 2` | `ease-out` | `rotate(±0.5deg)` | 弹动后 |
| 读数 count-up | `640ms` | ease-out-cubic（`rAF`） | 数字插值 | 揭晓 |
| 平衡针摆动 | `880ms` | `cubic-bezier(.65, 0, .35, 1)`（两端缓） | `rotate(0 → ±16deg)`，绕底部枢轴 | 选中表态 |
| 平衡针末端阻尼 | `80ms` | `ease-out` | `rotate(±1.2deg)` 回落 | 摆动后 |
| 张力条增长 | `520ms` | `cubic-bezier(.22, 1, .36, 1)` | `scaleX(0 → 1)`，`transform-origin: left` | 选中表态 |
| 空心三角淡入 | `280ms`（延迟 `300ms`） | `ease-out` | `opacity 0 → 1` | 揭晓 |
| 滑轨跟手 | `0ms` | — | 无过渡 | 拖拽中 |
| 滑轨吸附 | `220ms` | `cubic-bezier(.2, 0, 0, 1)` | `translateX` 到最近刻度 | 松手 |
| 仪表依次揭晓 | 间隔 `180ms` | — | — | 揭晓 |

### 4.2 关键实现要点

- **指针旋转**：`transform-box: view-box; transform-origin: 120px 120px;`（SVG 用户单位），不要用百分比 origin——SVG 元素的 `transform-origin` 百分比基准在部分浏览器里是视口而非元素盒。
- **摆动用 `transform` 不用 `top/left`**：避免重排，60fps。
- **只动 `transform` 与 `opacity`**：`box-shadow` 仅用于选中外环，不要动画化大面积阴影。
- **单一动效主轴**：一次点击只触发「指针弹动 + 针摆动 + 张力条 + 呼吸」这一组，不要让详情条也同时飞入——注意力应留在针与指针上。

### 4.3 `prefers-reduced-motion` 降级

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 1ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 1ms !important;
    scroll-behavior: auto !important;
  }
}
```

**降级后必须保留的信息通道**（不能因为关了动效就丢信息）：

| 动效通道 | 降级替代 |
|---------|---------|
| 指针位置 | 直接 `rotate()` 到目标角，无过渡，位置依然可见 |
| 读数数字 | 直接设为终值，**不做 count-up** |
| 空心三角 + 区间底纹 | 直接 `opacity: 1`，不淡入 |
| 呼吸光晕 | 关闭；选中的可读性改由**常驻 3px 外环 + 1.5px 实边**承担 |
| 平衡针摆动 | 直接跳到目标角；**中性区虚线保留可见**，针停在中性时仍能读出"零" |
| 张力条 | 直接 `scaleX(1)`，终态宽度即信息 |
| 入场 | 元素直接处于终态，不做位移淡入 |

> 原则：**动效是冗余通道，不是唯一通道**。关掉动效后，任何一条信息都不能丢失。

### 5.2 防横向滚动的硬性写法

```css
html, body { overflow-x: clip; }          /* 兜底，不是方案 */
* { min-width: 0; }                        /* grid/flex 子项默认 min-width:auto 会撑破 */
.grid > *, .flex > * { min-width: 0; }
.quote { overflow-wrap: anywhere; word-break: break-word; }   /* 长引语 / 长专名 */
svg { display: block; width: 100%; height: auto; }
input[type=range] { width: 100%; margin: 0; }  /* range 有默认内边距 */
```

> `min-width: 0` 是最关键的一条：`grid` 子项默认 `min-width: auto`，长中文引语或长英文人名（"meaningful and effective"）会让子项撑破容器，直接产生横向滚动。

### 5.3 375px 上的额外取舍

1. **事件块降密度**：375px 下每块保留「标记 + 时间戳 + 一行引语（最多 2 行，超出省略号）」，详情条再给完整逐字引语。
2. **仪表盘腹不放长标签**：读数下方一行 `11px` 名称（"布伦特" / "现货黄金" / "10Y 美债"），单位并入数值（`94` 下方 `USD`，`4100` 下方 `USD/oz`，`4.87%` 无单位行）。
3. **中缝不压缩成横条**：横向中缝在 375px 下无法同时容纳"两轨 + 针 + 轴标"，保持纵向 72px 更稳。
4. **触控热区 ≥ 44px**：事件块视觉高度可只有 `52px`，但 `padding` 保证点击区域 ≥ 44px。
