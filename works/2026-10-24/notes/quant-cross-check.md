### 1.2 是否仅一般政府 / 是否含央行持有（B）

- **"一般政府（general government）"= 中央政府 + 地区/地方政府 + 社会保障基金的直接债务**，**不含**公共企业（GFSM 2014 口径下邮政、公用事业等以市场方式提供商品服务的公共公司剔除在外）。惠誉主权方法论明确把"一般政府债务总额（含中央和所有地区、地方政府的直接债务）"当作跨国比较的首选指标；其"净债务"另行为"总额减去政府在金融机构的存款"。（来源：三大评级机构主权评级方法比较研究，2019-08-14，`http://qyxypj.com/index-article-info-id-391.html`；IMF GFSM 定义见 FRED 系列说明 `GGGDTP**A188N` 与 OECD 指标定义页 `oecd.org/es/data/indicators/general-government-debt.html`）
- **是毛额（gross），所以不扣减央行持有的国债**。IMF 对 gross debt 的定义是"所有需要未来支付利息和/或本金的负债（SDR、货币与存款、债务证券、贷款、保险/养老金/标准化担保、其他应付账款）"，估值"可用市值、名义值或面值"——定义里**没有任何"剔除公共部门内部持有"的步骤**。（FRED/IMF WEO 系列注记原文可核查）
- 实务含义：**日本央行持有的 JGB、美联储持有的美债都还在这 75万亿 里**。若改用"公众持有/净债务"口径，发达市场债务会明显下修（日本最甚）。**各国央行持有的具体占比本轮未取到可核查来源 → 属 C，作品中若要写"剔除央行持有后为X万亿"必须另找数据，不得估算。**

### 1.3 名义值 / 存量年份 / 利息财年（A）

- **名义美元、现价汇率折算**：惠誉给的是"USD75.4万亿 = DM GDP 的102%"，倒推 DM GDP ≈ **73.9万亿美元**（7月版 75.8/1.04 = 72.9万亿），两者自洽 → 是名义存量，不是实际值。
- **存量年份**：2026 **年末预测值**（"预计/恐破"），**不是已实现数据**。
- **利息的时窗**：IIF（2026-09-23 发布）的措辞在中文转译里出现两版——经济日报/财联社"**过去一年**"，新浪转财联社"**去年**"。两版都不是财政年度，而是**截至2025年或滚动12个月**的利息。
- **→ 分子分母年份错配**：3.3万亿（≈2025年实际）÷ 75.4万亿（2026年末预测）**跨了年份、也跨了机构**。这是"4.4%"这个比值最大的问题，见下节。

### 1.4 隐含利率 4.4% 是否与发达市场久期收益率自洽（C — 判定为"不可这样用"）

**算式 1（你的算法，本身没错）**
```
3.3 万亿 ÷ 75.4 万亿 = 4.377%   （若用 75.8 万亿：4.354%）
```

**算式 2（用惠誉自己披露的两个数做闭合检验）**
惠誉 4Q26/每经引文：*"全球10个最大发达经济体的10年期政府债券收益率中位数比未偿债务的**平均利率高161个基点**"*，且*"10个最大发达市场10年期收益率今年以来平均上升81bp"*（升幅最大：法国+135bp、意大利+108bp、美国+106bp、日本+94bp、英国+94bp）。
```
若平均付息率 = 4.38%（3.3/75 的隐含值）  → 10年期收益率中位数应 ≈ 4.38% + 1.61% = 6.0%
若平均付息率 = 3.06%（OECD口径反推，见算式3）→ 10年期收益率中位数应 ≈ 3.06% + 1.61% = 4.7%
```
观测值（本轮检索到的同期市场数据）：美国10年期 5.14%（10-20简报）／盘中高点 5.36%；30年期 5.444%；法国10年期逼近5%（24年新高）；英国30年期破6%（28年新高）；日本10年期破3%；意大利10年期约4.7%。**DM10 的10年期收益率中位数落在 4.6%–4.9% 区间。**

→ **第二种（3.0–3.1%）与惠誉自己的 161bp 数字闭合；第一种（4.4%）要求一个市场上不存在的 6.0% 中位收益率。结论：4.4% 不是发达市场的存量平均付息率。**

**算式 3（用 OECD 财政口径独立反推，作为量级校验）**
OECD《Global Debt Report 2026》/《Economic Outlook》（2026-09-23 前后）：*"利息支出目前已占该组织GDP的 3.3%"*（中文转译见网易《债券市场动荡：谁的威胁更大？》2026-10-12；西文转述见 El Boletin《El mapa de la deuda pública en 2026》，明确标注数据来源为"OCDE, Informe Global de Deuda 2026"）。
```
DM GDP ≈ 73.9 万亿（惠誉自身分母）
利息 ≈ 3.3% × 73.9 ≈ 2.2–2.4 万亿美元（OECD成员与"发达市场"不完全重合，取 70–74万亿 GDP 得 2.31–2.44万亿）
2.3 万亿 ÷ 75.4 万亿 ≈ 3.1%   ← 与算式2的第二种解一致
```
**即：财政账户口径的发达市场年利息约 2.3万亿美元量级，IIF 的 3.3万亿 比它高约 40–45%。** 差额来源本轮无法从一手方法论确认（可能：IIF 只统计"在国际市场交易的债券"但用当前市场收益率重定价整个市场、或含短期票据按政策利率滚动、或发达经济体样本更宽）→ **C：IIF 该数的具体构造公式未证实**。

**算式 4（美国单国硬数据锚，用于判断哪个量级更可信）**
美国财政部 2026-10-16 公布（每经/中财网 10-20 转述）：FY2026（截至9月30日）联邦赤字 **1.99万亿美元**（同比+12%，2021年以来最大，连续第四年高位），**净利息 1.05万亿美元**（同比+814亿美元，创纪录，已是第三大支出项）。
```
1.05 万亿 ÷ 公众持有债务（约30万亿，≈GDP的100%）= 3.5%
1.05 万亿 ÷ 联邦总债务（约40万亿）= 2.6%
```
美国是DM里平均票息偏高、期限偏短的一档（惠誉称低利率时代债务集中在美法英），**取上限 3.5% 仍显著低于 4.4%**。CRFB 测算（网易 10-12 转述）：若借贷成本维持当前水平，美国年利息将在十年内增至约 2.8万亿——**说明"当前市场收益率"到"存量平均付息率"的传导是逐年推进的，现在还不等于 4.4%。**

### 2.3 是否含长期租赁承诺 / 表外融资（C — 结论：大概率不含，且这是标普自己的告警点）

### 2.4 年均 1.17万亿 vs 2026 实际指引：后段陡增吗？（A — 不陡增，反而内嵌减速）

**算式 5（7万亿的可行性）**

### 2.5 "负自由现金流"的口径（A — 标普有公开方法论文档）

S&P Global Ratings《Corporate Methodology: Ratios And Adjustments》（criteria 文章，`spglobal.com/ratings/en/regulatory/article/-/view/sourceId/10906146`，另见评级报告脚注的标准定义）原文：
```
FFO  = EBITDA − 现金利息支出 − 现金税费
FOCF = CFO（经营活动现金流）− 资本开支
```
关于租赁（同一 criteria 体系内）：
- **调整后债务**要把"表内与表外、用于取得长期使用长期资产（含租赁负债）且所有权收益归公司的承诺"加进去；经营租赁按**未来租金现值（7%折现）**加进债务。
- **但"基础口径的资本开支——以及由此得出的 FOCF——不含与经营租赁/融资租赁相关的隐含资本开支"**；标普只对"租赁密集型行业"**另设**一个含租赁隐含 capex 的调整版 FOCF 指标。

**→ 三点可直接写进附录的结论：**
1. 口径是 **FOCF = CFO − capex**，**不是** FCF = 净利润 + D&A − capex − 营运资本 那种自由现金流，也**不扣股息与回购**（那在 FOCF 之后）。
2. **经营租赁租金**在 CFO 内（压低 FOCF）；**融资租赁本金偿还**在筹资活动（不压 FOCF）；**通过 SPV/JV 建成的资产**若形成的是租赁付款而非自有 capex，则**同时不进 capex、不进 FOCF 的减项**——即 **FOCF 的"负值"会低估现金负担**。标普自己在监控的正是这一点（"contractual commitments and other debt-like obligations"）。
3. 时间口径与"至少在明年之前"的中文表述一致：**2026 与 2027 两年六家全部为负 FOCF，恢复要到 2029，2028 是拐点**（"至少到明年之前为负"→ 指 2026、2027，不是"2026 年底前")。

**旁证（机制，非口径）**：高盛预计 **2026 年超大规模云厂商资本开支占其经营现金流的比例升至约 100%**（证券时报 7-05 转述）——**这正是"负 FOCF"的直接机制：capex ≈ CFO ⟹ CFO − capex ≈ 0 或为负。**
**对手锚（用于"账本"的另一侧，注意是不同机构）**：Gartner 称 AI 数据中心拥有者需在 2030 年底前产生 **8.5万亿**美元收入才能覆盖成本并获得健康回报，而预测消费者与企业对 AI 服务的开支"**最多 3.6万亿**"，并警告当下投资趋势可能使**超过 4万亿**资产价值在 2032 年前面临减值（新浪 10-22 转述）。→ 若作品要用，必须**与标普的7万亿分开署名**，两者不可混为一张账单。

## 3. 议题三：口径红线复核（"不得写背离"）

### 3.1 CME 三个数是嵌套还是互斥？——**你给的理由错了**（A，纯算术可判定）

简报原文（财联社 10-20 06:05）：到10月 **维持不变 82.8%**、**累计加息 25bp 17.2%**；到12月 **维持不变 6.4%**、**累计加息 25bp 77.8%**、**累计加息 50bp 15.8%**。

**判定测试（和是否为100%）**
```
10月：82.8 + 17.2 = 100.0   ✓ 完备划分
12月：6.4 + 77.8 + 15.8 = 100.0   ✓ 完备划分 → 三个数互斥
```
**反证**：若 77.8% 是"≥25bp"、15.8% 是"≥50bp"（嵌套），则 P(维持不变) = 100 − 77.8 = **22.2%**，与公布的 **6.4%** 直接矛盾。→ **嵌套读法不可能成立。**

**正确的换算**：这些是 FedWatch 对"12月末利率落在哪个目标区间"的**互斥结果分布**（现行为 3.75%–4.00%，故 +25bp = 4.00–4.25、+50bp = 4.25–4.50），"累计"指从今天起跨过10月与12月两次会议的**合计变化**。所以——
```
P(12月前至少再加一次25bp) = 77.8 + 15.8 = 93.6%   ← 互斥事件相加，合法且必须相加
P(全年恰好加2次)          = 77.8%
P(全年加3次)              = 15.8%
P(全年只加1次)            = 6.4%
```
**"至少加两次"这件事本身=100% − P(只加1次) = 100% − 6.4% = 93.6%（因为9月已加1次）。**

**内部自洽性检验（我做的分解，可当作附录用的高价值算式）**
```
设 P(10月加)=17.2%，P(10月加且12月加)=15.8%（唯一能凑出累计+50bp的路径）
→ P(只加10月) = 17.2 − 15.8 = 1.4%
→ P(只加12月) = 77.8 − 1.4 = 76.4%
→ 校验 P(10月不动) = 76.4 + 6.4 = 82.8% ✓ 与公布值精确吻合
→ P(12月加息) = 76.4 + 15.8 = 92.2%
→ P(12月加息 | 10月不动) = 76.4/82.8 = 92.3%
→ P(12月加息 | 10月加息) = 15.8/17.2 = 91.9%
```
两个条件概率几乎相等（92.3% vs 91.9%）——**这组数不可能是拼凑的，是一套自洽的分布**。外部佐证：路透 10-15 汇编"**期货定价10月加息约27%、12月约89.5%（CME FedWatch）**"，与上式推出的12月约92%同量级。

### 3.2 Polymarket "2026仅加息1次" NO=79% 是否等于"至少加两次"？——**成立，但成立的理由不是"嵌套"**（A）

**合约事实（可核查）**
- 合约名 "**Will 1 Fed rate hike happen in 2026?**"，上线 2026-06-23，结算 2026-12-31；10-20 读数 **YES 20.5% / NO 79.5%**（Vultax 10-20 03:24 UTC；PredictionBubbles 10-22 00:04 UTC 读数 YES 20.5%）。Polyrama 10-22/23 读数 YES 24–25% / NO 75–76%（**两日抬升 4pt，说明这不是高精度读数**）。
- 它是多结果合约 "**How many Fed rate hikes in 2026?**" 中"1 (25 bps)"这一档。同页其余档：
```
1次 20.5% ｜ 2次 68.5% ｜ 3次 10.1% ｜ 4次 0.8% ｜ 5次以上 0.4%   （合计 100.3%，超出部分为价差/overround）
→ P(≥2次) = 68.5 + 10.1 + 0.8 + 0.4 = 79.8% ≈ NO 79.5%  ✓ 差 0.3pt
```

**为什么"0次"分支不干扰这个换算（关键，也是你原来缺的那一步）**
> 美联储已于 **2026-09-16** 以 **12-0 全票**加息 25bp，将联邦基金利率目标区间上调至 **3.75%–4.00%**，为 **2023年7月以来首次加息**（新华社/央视/上证报/中新网 2026-09-17）。
> 因此"2026全年加息次数 = 0"**在9月16日之后概率恒等于 0**（历史事件不可撤销）。
> 于是 NO("不是恰好1次") = P(0次) + P(≥2次) = **0 + P(≥2次) = P(≥2次)**，严格等价。
> 旁证：姊妹合约"Will no Fed rate hikes happen in 2026?"（同批 6-23 上线）在 9-17 已成交于 **No 95–100%**。

**→ 结论：换算成立，但必须在附录里写出"9月已加一次"这个前提，否则懂概率的读者会立刻指出 NO 还包含"0次"。**

**"方向一致"的同事件对比表（作品可直接引用）**

| 2026全年加息次数 | CME FedWatch（10-20 06:05，由两次会议推得） | Polymarket（10-20） | 判断 |
|---|---|---|---|
| **恰好 1 次**（10月与12月都不加） | **6.4%** | **20.5%** | 两边都是小概率 |
| **恰好 2 次** | **77.8%** | **68.5%**（众数档） | 两边都是**众数** |

| **至少 2 次（=红线结论）** | **93.6%** | **79.5–79.8%** | **同向；差 14pt** |

**第三方（卖方预测）同向佐证**：
- **巴克莱**：2026-10-15 路透汇编里仍是"**1次（12月）**，终点 4.00%–4.25%"；**2026-10-16 上修**（9月 CPI/PPI 超预期后，Mark Giannoni 团队）→"**12月和明年1月各加息25个基点**，随后较长时间维持 **4.25%–4.50%**"（华尔街见闻 10-16 23:37）。→ **简报"巴克莱预计12月与1月各加25bp"属实**；注意 1月属 2027 年，**对"2026全年2次"的判断无影响**。
- **美联储点阵图（9月SEP）**：18 名提交预测者中 **12 人预计年内还加1次、4 人预计还加2次、2 人预计不再加、无人预计降息**；年末利率中值由 6 月 3.8% 上调至 **4.1%**（上证报/中新网 9-17）。→ **中位路径 = 全年恰好2次 = 两套市场读数的众数。**

### 3.3 为什么"背离"是错的（红线确认 + 更准确的表述）

简报原句（Polyrama 10-19 转述）："Polymarket '2026年仅加息1次' YES 21%、NO 79%，**与CME对12月加息77.8%的定价明显背离**。"
**错在哪**：把 **两个不同事件** 当成同一个事件对比——
- Polymarket 的 21% 是"**全年恰好1次**"；
- CME 的 77.8% 是"**到12月累计+25bp**"，即"**全年恰好2次**"。
这两数**本来就该一低一高**（20.5% vs 77.8%），它们是互补方向的邻居，不是同一命题的两个价格。**同事件对照后：只加1次 = 6.4% vs 20.5%；至少两次 = 93.6% vs 79.5%，方向完全一致。**

**⚠️ 另一个陷阱（请不要用它当交叉验证）**：Polymarket"美联储12月会议后加息25个基点" YES **77.5–78%**（10-20 23:17 UTC 读数 77.5%）与 CME"到12月**累计**+25bp 77.8%"数字几乎相同——**但事件不同**（单次会议 vs 两次会议累计）。按 §3.1 的分解，CME 对应的"**12月单次会议加息**"概率是 **92.2%**，比 Polymarket 的 77.5% 高约15pt。把 77.8% 和 77.5% 当成互相印证，**会被专业读者一眼看穿**。

**场地差异的可核查解释（写成一句话放进附录）**：9月17日同一时点，重建的 FedWatch（用 CBOT 30天联邦基金期货）给出 10月 50%／12月 79%，而 Polymarket 为 45%／70%、Kalshi 46%／70% ——**期货读数系统性比预测市场鹰派 3–9 个百分点**（FinanceFreedomPath 2026-09-17，明说"因为CME自己的工具屏蔽了访问，我们从CBOT结算价手工重建"）。加上线上市场合约的**极薄流动性**（该合约累计成交约 **48–52万美元**、24小时 **0.5–2.6万美元**、订单簿深度 **9–18.5万美元**，对手方是机构主导、名义数十亿美元的联邦基金期货市场）——**14pt 的差距落在"场地结构 + 流动性噪声"内，不构成方向性分歧。**

### 3.4 "10月不变82.8%"与"10月累计+25bp 17.2%"并存是否正常？——**完全正常，不是矛盾**（A）

```
82.8% + 17.2% = 100.0%
```
同一会议、两种互斥结果、相加为1 → **这就是概率分布本身**，与"抛硬币正面48%、反面52%"同理。要写成"矛盾"需要出现如"不变82.8% + 加息30%"这种和≠100%的情形。
并且与12月的表也能互相闭合（见 §3.1 分解）：10月的 82.8%/17.2% 与12月的 6.4%/77.8%/15.8% 是**同一棵树上的两层**，不是两套互相打架的预测。
**作品里若把这两数并列展示，标注应为"同一分布的两个互补分支（相加=100%）"，而不是"两个市场的分歧"。**
