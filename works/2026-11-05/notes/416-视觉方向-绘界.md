## 一、视觉世界观：「无影灯下的权重手术」

一句话：**暗色手术台 + 示波器信号色 —— 整页是一台正在给小模型做微创手术的监护仪。**

页面不讲"AI 很厉害"，而讲"切口极小、读数极准"。所有视觉元素都来自手术室与监护仪的实物隐喻：

| 隐喻物 | 页面对应物 | 作用 |
|---|---|---|
| 无影灯 | 页面顶部一块 `#05080B` 深渊区 + 顶部径向微光 | 只打亮手术野，四周压黑 |
| 手术准星 | 覆盖在"被改写的权重格"上的 crosshair | 锁定 0.016% 的切口位置 |
| 监护仪波形 | 分隔线、章节间的 ECG 细线 | 提供节奏，不抢正文 |
| 权重矩阵 | 48×48 网格，绝大多数空格，仅一格点亮 | 表达"极小比例的改写" |
| 能力条 + 卡尺端头 | 数据区块的横条，端头是卡尺爪而非箭头 | 表达"被量出来的约 6 倍" |
| 灭菌单色 | 全页只有绿（在体征）+ 琥珀（读数）+ 一个红（告警） | 拒绝彩虹，制造专业克制感 |

**为什么不是"赛博朋克/霓虹紫"**：手术世界观的张力来自**极暗背景上的极少高亮**，不是来自多色霓虹。多色会让 0.016% 这个"极小量"失去视觉重量。

### 1.2 对比度验证（≥4.5:1）

**验证方式**：WCAG 2.x 相对亮度公式，脚本 `python3 /tmp/contrast.py` 实算（sRGB 线性化：`c≤0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4`；`L=0.2126R+0.7152G+0.0722B`；`ratio=(Lmax+0.05)/(Lmin+0.05)`）。

| 文字/元素 | 前景 | 背景 | 比值 | 结论 |
|---|---|---|---|---|
| 正文 | `#E8EFEC` | `#0A0F14` | **16.48** | ✅ ≥4.5 |
| 正文（面板上） | `#E8EFEC` | `#121A22` | **15.03** | ✅ ≥4.5 |
| 正文（深渊区） | `#E8EFEC` | `#05080B` | **17.20** | ✅ ≥4.5 |
| 次要文字 | `#A9B8C2` | `#0A0F14` | **9.46** | ✅ ≥4.5 |
| 次要文字（面板上） | `#A9B8C2` | `#121A22` | **8.63** | ✅ ≥4.5 |
| 弱文字 | `#8A9AA6` | `#0A0F14` | **6.65** | ✅ ≥4.5 |
| 主色作文字 | `#37E0A6` | `#0A0F14` | **11.34** | ✅ ≥4.5 |
| 辅色作文字 | `#6E8BFF` | `#0A0F14` | **6.23** | ✅ ≥4.5 |
| 强调色作文字 | `#FFB020` | `#0A0F14` | **10.52** | ✅ ≥4.5 |
| 告警色作文字 | `#FF5C7A` | `#0A0F14` | **6.47** | ✅ ≥4.5 |
| 深色文字压主色按钮 | `#0A0F14` | `#37E0A6` | **11.34** | ✅ ≥4.5 |

**算式结论**：11 组全部 ≥4.5:1，最低 **6.23**（辅色 `#6E8BFF` on `#0A0F14`）。正文主组合 16.48，余量充足。未验证项：375px 小屏下实际渲染字体的字重/字号组合 —— 需在真机浏览器复核。

**自定义 token 写法（CSS，零依赖）**：

```css

}
body{background:var(--bg);color:var(--ink);}
```

## 二、可内联 SVG motif（3 个）

**统一风格规范**：`viewBox="0 0 48 48"`，`fill="none"`，`stroke="currentColor"`，`stroke-width="1.5"`，直角端点（手术器械感，不用圆头），无滤镜、无渐变、无外部引用。父级设 `color:` 即可整体换色；需要双色时用 `stroke: var(--sig)` 覆盖单个 `<g>`。

### 2.1 手术准星 crosshair

```html
<svg viewBox="0 0 48 48" width="48" height="48" fill="none"
     stroke="currentColor" stroke-width="1.5" aria-hidden="true" focusable="false">
  <circle cx="24" cy="24" r="15"/>
  <path d="M24 3v12M24 33v12M3 24h12M33 24h12"/>
  <path d="M24 16v4M24 28v4M16 24h4M28 24h4" stroke-width="1"/>
  <path d="M13.4 13.4l4.2 4.2M34.6 13.4l-4.2 4.2M13.4 34.6l4.2-4.2M34.6 34.6l-4.2-4.2"
        stroke-width="1" opacity=".55"/>
  <rect x="22" y="22" width="4" height="4" fill="currentColor" stroke="none"/>
</svg>
```

**用法**：绝对定位叠在被点亮的权重格上，`color: var(--read)`。四角刻线用 `opacity=".55"` 做层级，不另加颜色。

### 2.2 权重格 weight-cell

```html
<svg viewBox="0 0 48 48" width="48" height="48" fill="none"
     stroke="currentColor" stroke-width="1.5" aria-hidden="true" focusable="false">
  <rect x="6" y="6" width="36" height="36"/>
  <path d="M15 6v36M24 6v36M33 6v36M6 15h36M6 24h36M6 33h36" stroke-width="1" opacity=".45"/>
  <rect x="24" y="15" width="9" height="9" fill="currentColor" stroke="none"/>
  <path d="M24 19.5h9M28.5 15v9" stroke="var(--bg,#0A0F14)" stroke-width="1"/>
</svg>
```

**用法**：整块矩阵用 `color: var(--ink-3)` 画线，`<g>` 单独设 `color: var(--sig)` 点亮那一格。矩阵只点亮一格，视觉上直接表达"极小比例的改写"。格内十字用背景色反白，与准星 motif 同语言。

### 2.3 能力条端头（卡尺爪）

```html
<svg viewBox="0 0 48 48" width="48" height="48" fill="none"
     stroke="currentColor" stroke-width="1.5" aria-hidden="true" focusable="false">
  <path d="M6 30V18"/>
  <path d="M6 24h22"/>
  <rect x="6" y="21" width="22" height="6" fill="currentColor" stroke="none"/>
  <path d="M28 12v24"/>
  <path d="M28 24h14"/>
  <path d="M42 19v10"/>
  <path d="M34 21v6M38 22v4" stroke-width="1" opacity=".55"/>
</svg>
```

**用法**：横条 = 能力值，`M28 12v24` 那道竖线 = **卡尺端头**（不是箭头、不是圆点），刻度短线用 `opacity=".55"`。端头之后的余量留白 = 还有提升空间。配色 `color: var(--read)`。

## 三、字体栈（零远程依赖，仅系统字体）

**规则**：不 `@import`、不 `@font-face` 外链、不 `<link>` CDN。只用 `font-family` 引用本机已装字体。

**正文 / 标题（中文优先，跨平台）**

```css
font-family: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue",
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC",
  "Source Han Sans SC", "WenQuanYi Micro Hei", sans-serif;
```

**数据 / 读数 / 坐标刻度（等宽，制造仪器感）**

```css
font-family: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas,
  "Liberation Mono", "DejaVu Sans Mono", "Courier New", monospace;
font-variant-numeric: tabular-nums;  /* 数字等宽对齐，读数不跳动 */
```

**可选：章节编号 / 引文（衬线，仅此一处使用）**

```css
font-family: Georgia, "Times New Roman", "Songti SC", "SimSun", serif;
```

**排版要点**

- 标题字重 650–700，正文字重 400，字距 `-0.01em`（中文标题）/ `0`（正文）。
- 正文行高 `1.7`，段宽 `min(68ch, 100% - 2rem)`，375px 下左右留白各 `16px`。
- 数字与 `%`、`×` 之间用等宽字体并加 `font-variant-numeric: tabular-nums`，避免动画时宽度抖动。

## 四、动效原则（5 条，全部尊重 `prefers-reduced-motion`）

**总开关（写在最外层，先于任何动画声明）**

```css
@media (prefers-reduced-motion: reduce){
  *,*::before,*::after{
    animation-duration:.001ms !important;
    animation-iteration-count:1 !important;
    transition-duration:.001ms !important;
    scroll-behavior:auto !important;
  }
}
```

1. **只动"信号"，不动排版。** 准星呼吸、扫描线掠过、权重格点亮这三处可以动；标题、正文、卡片位置永远不动。任何动画只改 `transform` 与 `opacity`，不改 `width/height/top/left`，不触发重排。
2. **入场一次性，600ms 内结束。** 章节进入视口只播一次（`IntersectionObserver` + `once`），绝不循环。背景扫描线若循环，周期 ≥6s 且透明度 ≤0.18，避免持续视觉噪音。
3. **`reduce` 下直接给终态。** `prefers-reduced-motion: reduce` 时：所有 `animation` 关闭，元素直接呈现最终状态（权重格已是点亮态、能力条已是满值、准星静止在位）。**不得用 JS 强行播放**，不得以"没动效会看不懂"为由保留运动。
4. **帧预算 60fps。** 动画属性限定 `transform` / `opacity`；禁止动画 `filter: blur()`、`box-shadow` 扩散、`background-position` 滚动纹理。GPU 合成层用 `will-change: transform` 只加在确实持续动画的那 1–2 个元素上，动画结束移除。
5. **数字增长只在 `reduce` 之外做，且一次性。** 能力条从 0 涨到终值用 `requestAnimationFrame` 单次跑完（≤900ms，`cubic-bezier(.22,1,.36,1)`）；`reduce` 模式下跳过 rAF，直接写终值。数字用 `tabular-nums` 防抖宽。

## 五、「不要做」清单（本世界观下的 AI slop 禁忌）

1. **不要蓝紫渐变 hero + 居中大标题 + 两颗胶囊按钮** —— 这是通用 AI 落地页模板，与手术台隐喻完全无关，会立刻把作品降级成"某个 SaaS 首页"。
2. **不要霓虹多彩 / 彩虹热力 / 多色 glow 叠加** —— 本世界观只有绿（在体征）+ 琥珀（读数）+ 至多一处红（告警）。出现第四种彩色即违规；多色会让"极小的改写量"失去视觉重量。
3. **不要玻璃拟态卡片 + 多层投影 + 毛玻璃模糊堆叠** —— 手术室是哑光、无反光的。层级只靠 `#0A0F14 / #121A22` 两档底色与 1px 描边表达，阴影最多一层且 `opacity ≤ 0.25`。
4. **不要 emoji 当图标（🚀 💡 🤖 ✨）** —— 图标一律用上文 SVG motif 或同风格内联线性图形，`stroke-width` 统一 1.5。
5. **不要粒子背景、无限视差、滚动劫持** —— 装饰性运动不能提供信息；准星与扫描线是唯一被允许的运动，且都承载语义。
6. **不要无意义数字与百分比** —— 全页**只允许 0.016% 和 约 6 倍两个数字**，均标 🟡中置信度。不得补充任何来源之外的提升幅度、准确率、参数量、评测分数。
7. **不要远程资源** —— 不引 Google Fonts / CDN 图标库 / 外链图片 / 外链 SVG sprite。字体只用系统栈，图形全部内联。
8. **不要空话文案** —— 禁用"赋能、闭环、重新定义、颠覆、极致、引领未来"。文案写手术动作：切口、缝合、读数、复核。
9. **不要居中通栏长段落** —— 正文左对齐、限宽 68ch；居中只留给 hero 的准星与单行读数。
10. **不要 375px 断点以下出现横向滚动** —— 表格与权重矩阵在窄屏改为纵向堆叠或 `overflow-x:auto` 容器，不得撑破视口。
