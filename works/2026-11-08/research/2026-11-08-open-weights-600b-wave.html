594B 下周落盘：开源冲刺能力上限，闭源收紧访问控制的分水岭周

2026 年 11 月 4 日至 8 日，五款模型在五天内发布或开放：混元 Hy4 正式版、Inkling 2 Small、Ling-3.2-flash、ERNIE-5.5-Flash-Base、Kimi K3.1 Pro。同一天，OpenAI 给 GPT-6 Cyber 装上了 IP 允许列表。本页把两份简报的汇总口径逐条对回官方原文，并标出哪些「开源」其实还没开。

制作：研析 · 成本与参数口径核算：量研 一手核源：Thinking Machines Lab、OpenAI、蚂蚁百灵开发者文档、中国经济网转官方发布稿 核源日期：2026-11-08

结论

分水岭不在能力高低，而在通道宽窄：开源侧把 594B 到 2.8 万亿参数的权重推向可下载，闭源侧把旗舰模型的分发收进「获批组织 + IP 允许列表」，两侧同时把安全评估前置成放行条件。

五天里的两条反向曲线可以各自验证。开源一侧，Inkling 2 Small 官方写明 Apache 2.0 权重要「经外部安全测试与红队测试完成后」下周放出，混元 Hy4 正式版写「将于近期开源模型权重，发布模型系统卡片」，而 Ling-3.2-flash 只开 API、官方文档没有写权重开放；也就是说，这一周真正挂上「已开源」标签的只有 ERNIE-5.5-Flash-Base 与 Kimi K3.1 Pro。闭源一侧，OpenAI 的 GPT-6 Cyber 系统卡把网络安全能力标为 Critical，并写明 Daybreak Red API 默认要求 IP 允许列表、模型只对获批用户与组织开放。能力在扩散，通道在收窄，两边的闸门都往前挪了一步。

核源：两处升级，两处修正

简报是汇总转述，本页把它逐条对回一手原文。四条候选断言里，两条来源升级，两条口径要改。

  1. 594B：从「汇总口径」升为官方公告

    简报焦点3 写的是汇总转述。本页直接取到 Thinking Machines Lab 官方公告页，原文给出 594B 总参数、17B 激活、1M 上下文，并说明是带图像输入与可变推理努力的 MoE。

    结论：该数字为官方公告，来源等级升级。

  2. 「12T token 68 小时」：两个口径被合并了

    官方公告里，68 小时只对应 H1 阶段的 8.4T token，跑在 NVIDIA GB300 NVL72 机架上。全预训练分四段：8.4T + 3.8T + 约 320B + 约 34B ≈ 12.55T token，官方没有给后三段的时长；此外主强化学习 run 另跑 9 天、2048 GPU、超过 4×10²³ FLOPs、3T 以上 token。

    结论：简报「12T token 仅用 68 小时训完」把总训练量与单阶段时长合并了。页面把该断言改写为预训练 H1 阶段 8.4T token 用 68 小时。

  3. Ling-3.2-flash：参数核实，「开源」标签降级

    蚂蚁百灵开发者文档（2026-11-05 更新）确认 560B 总参数、25B 激活、1M 上下文，与简报「5600 亿总参、250 亿激活、100 万 token」一致。但同一份文档没有写 3.2-flash 的权重开放；文中明确写已开源的是 Ling-3.0-flash-VL，多家媒体也核到本轮未见 3.2-flash 的开源权重页。

    结论：参数口径官方核实；开放状态按仅 API 记录，不计入已开源。

  4. GPT-6 Cyber：从单一来源升为官方系统卡

    候选断言原标「单一来源（BYOBot AI Daily）」。本页取到 OpenAI 部署安全系统卡，Critical 网络安全评级与 Daybreak Red API 默认 IP 允许列表两句均为原文，另有「模型只对获批 Daybreak Red 用户与组织开放」。

    结论：两条断言来源升级为官方系统卡，可入 claims。

两侧其实在做同一件事：把闸门前移

开源侧的闸门管的是权重何时放出，闭源侧的闸门管的是用户如何进入。位置不同，动作一致：先评估，后分发。

开源侧：冲刺能力上限

能力规格 · 训练规模 · 权重状态
  • 规格上探：2.8 万亿、770B、594B、560B、280B，全部为 MoE，每 token 激活 14B 至 104B。
  • 上下文 1M 成为新基线：五款里四款标称 1M，ERNIE 训练 128K、推理支持 1M。
  • 训练量披露集中在两家：ERNIE-5.5-Flash-Base 33.5 万亿 token，Inkling 2 Small 全预训练约 12.55 万亿 token，另加 9 天强化学习。
  • 但「开源」被拆成四档：已开源 2 款、承诺下周 1 款、承诺近期 1 款、仅 API 1 款。
  • 闸门前移的证据：Inkling 权重要等外部安全测试与红队；Hy4 同步发系统卡片并写「更负责任的开源」；Kimi 与 ERNIE 都用自定义许可加条件。

闭源侧：收紧访问控制

评级 · 名单 · 网络边界
  • 能力评级先行：OpenAI 系统卡把 GPT-6 Cyber 的网络安全能力标为 Critical，与 GPT-6 Astra 同级，生物与化学领域标为 High。
  • 分发三层收紧：只对获批用户与组织开放、Daybreak Red 名单制、API 默认要求 IP 允许列表。
  • 官方给出的理由是降低被盗凭证的可用性，把请求来源限制在获批网络内。
  • 结果是能力上探与通道收窄发生在同一周：模型更强，能拿到模型的人更少。
